# FitGate for macOS

独立于浏览器运行的本地桌面应用。从现有 FitGate 插件复用动作库、动作示范图、MoveNet 模型、姿态判定、深蹲和开合跳计数、拉伸计时和音效。桌面提醒使用全屏遮挡与居中活动卡片，显示休息倒计时、动作、组数和操作按钮。两端共享 `packages/workout-core`；本目录拥有独立的运行与构建命令，依赖统一在仓库根目录安装。

## 打开应用

从 [GitHub Releases](https://github.com/longhaiqwe/fitgate/releases) 下载对应芯片的压缩包，解压后把 `FitGate.app` 拖到“应用程序”文件夹。在苹果菜单 → 关于本机中查看芯片类型。

| Mac 芯片 | 安装包 |
| --- | --- |
| Intel | `FitGate-<版本>-macOS-x64.zip` |
| Apple Silicon（M 系列） | `FitGate-<版本>-macOS-arm64.zip` |

两个版本均要求 **macOS 13 Ventura 或以上**。Electron 44 已不支持 macOS 12；之前文档中的 macOS 12 要求有误。Intel 包在 Intel Mac 上无需 Rosetta。每次发布的实测环境与边界见 [兼容性报告](COMPATIBILITY.md)。

正式发行流程使用 Developer ID 签名和 Apple 公证，并在 ZIP 中附带公证票据；以对应 Release 的验证记录为准。旧版 1.1.0 仅有 ad-hoc 签名，不应被当作已公证版本。首次打开已公证的应用时，macOS 仍可能显示普通的“从互联网下载”确认，这是正常提示。摄像头和浏览器自动化权限仍需按功能使用时授权。

从源码运行无需 Apple 开发者账号。普通 `npm run package` 生成开发用 ad-hoc 包；维护者正式发布请使用[签名与公证流程](docs/releasing.md)。

关闭主窗口后，菜单栏仍会继续监控。点击菜单栏图标可开始伴练、暂停、继续或退出。使用 ⌘Q 可完全退出。

## 功能

- **电脑活跃使用计时**：默认统计所有前台应用；打开 FitGate 自身和进入伴练不累计。无需辅助功能或屏幕录制权限。
- **三种监控范围**：整台电脑、指定应用、指定网站。指定应用列表包含正在运行的应用与已选择的应用。
- **网站模式**：复用原插件平台开关、自定义域名、YouTube / Shorts 独立规则。支持 Safari、Chrome、Edge、Brave、Arc；通过系统 Apple Events 查询当前标签页，每两秒一次，不存储完整 URL。第一次使用需允许“自动化”权限。Firefox 和其他浏览器可使用整台电脑或指定应用模式。
- **空闲与休眠处理**：默认没有键鼠活动 1 分钟后暂停，可选 30 秒至 15 分钟。锁屏和系统休眠立即暂停；连续空闲、锁屏或休眠达到 5 分钟后重置当前周期，可选择 2／5／10／15 分钟。同一次空闲只记录一次“空闲休息”，不计入动作完成或已验证站立；当重置阈值早于空闲暂停阈值时，也会停止累计。伴练及持续识别到站立时，不因键鼠空闲提前重置。重新打开应用后根据系统实际空闲状态判断，不把关闭应用期间一律当作休息。看视频等长时间无输入的场景可适当调高空闲暂停与重置阈值。
- **休息提醒**：默认 25 分钟 / 1 组。累计达到上限后覆盖所有显示器，包括菜单栏和 Dock 所在区域。窗口不可拖动、缩放或最小化，点击卡片外不会关闭；切换普通应用后恢复提醒焦点。支持跨 Space 和全屏应用显示，显示器变化时保持覆盖。活动卡片居中显示 5 分钟倒计时：开启摄像头时只累计识别到站立的时间，只需双肩、髋部和膝盖入镜，无需脚踝；坐下、关键部位遮挡、离镜或视频中断时暂停，累计满 5 分钟记录 1 组「站立 5 分钟」并重置周期；关闭摄像头时保留纯休息计时，不记录站立动作。多屏仅一个提醒窗口使用摄像头，其他屏幕同步进度。摄像头授权或模型失败不会自动通过，预览不会开启摄像头；到期伴练继续覆盖当前屏幕，其他屏幕保留提醒，未完成时可返回休息提醒。休息结束或完成伴练后解除遮挡并重置周期。可推迟 5 分钟，Escape 或关闭真实提醒窗口也可推迟。预览中的关闭操作会解除全部预览遮挡，不更改使用周期。
- **完整伴练**：坐姿 5 个动作、站立 11 个动作、居家 13 个动作；随机动作或指定动作；1–5 组串联；本地摄像头姿态识别或无摄像头纯计时；深蹲深度设置、暂停、重新开始及节奏音效。
- **深蹲识别**：建议侧身对着摄像头，先站直再开始下蹲；练习页顶部、动作步骤和准备提示均标明侧身建议，无需脚踝入镜。正面或脚踝不可见时，先站直保持片刻，以可见的肩部、髋部和膝盖建立基准，再按髋部相对膝盖的下降及肩部随动估算下蹲进度，尺度参照躯干长度。侧面只有一侧肩、髋、膝可见时也可使用；侧面脚踝可见时保留膝关节夹角判断。达到深度后回到站直位置才计一次；已校准的肩、髋或膝持续丢失会取消本次动作并重新校准，脚踝的出现或消失不影响已建立的进度判定。进度是图像估计值，不代表真实关节角度。
- **本地统计**：今日受控范围活跃时长、按应用分布、最近 7 天趋势、完成活动次数及组数。点击今日完成活动卡片可查看日／周／月／年动作明细和完成趋势，并翻看历史周期；点击动作可查看该动作的日／周／月／年完成次数与趋势。使用记录支持日／周／月／年总时长、趋势和各应用用时汇总，点击应用可查看其独立的周期用时与趋势，返回时保留列表周期；每日汇总与应用用时持续保留，支持 JSON 导出。
- **提醒事件统计**：今日概览及活动记录的日／周／月／年视图分别显示正式提醒、推迟和计时休息次数。正式提醒首次就绪时记录，同次提醒的多屏展示、短暂锁屏恢复及未完成伴练返回不重复；推迟后再次到点提醒记为新的一次。预览不计数。无摄像头休息倒计时完成才记录计时休息，不计入动作完成或空闲休息；中途推迟、开始伴练或被空闲重置的倒计时不计完成。按事件发生的本地日期汇总，新增字段从本版本开始记录，旧数据缺失项按 0 展示。
- **提醒前预告**：默认提前 60 秒发送系统通知，可在规则设置中选择关闭、30 秒、60 秒或 120 秒；预告期间菜单栏显示剩余秒数。同一轮不重复预告，推迟后会按新的提醒时间再次预告。空闲、暂停和非受控范围不触发预告，系统通知的显示受 macOS 通知设置影响。
- **定时暂停**：主面板顶部与菜单栏可选择暂停 30 分钟、1 小时、到明天本地时间 00:00，或暂停至手动恢复。暂停时显示截止时间，支持提前恢复；重启或唤醒后仍按原截止时间恢复，不补计暂停期间的时长。
- **动作历史兼容**：新完成记录按稳定动作 ID 保存，界面显示当前动作名称；已有名称记录自动归并到对应 ID，无法匹配的旧动作保留原名，未记录动作明细的组数不会猜测归属。
- **桌面集成**：菜单栏剩余时间、单实例运行、窗口关闭后继续工作、登录时启动（在打包应用中启用）。

提醒提供应用层面的全屏遮挡，不是 macOS 系统账户锁；保留推迟、退出应用和系统强制退出。摄像头系统授权期间允许操作授权对话框。动作图和提示沿用插件；姿态识别只是运动辅助，不是医疗评估。

## 数据与权限

所有动作图和 AI 模型随应用打包，不依赖外部 CDN。摄像头画面在本机内存中处理，不保存视频。基础计时只读取系统空闲状态和前台应用标识，不监听或存储输入内容。指定网站模式需要浏览器自动化权限，但不保存浏览历史。

设置、当前周期和按日记录写入 `~/Library/Application Support/FitGate/fitgate.json`，每 5 秒以及关键操作时保存。采用临时文件加原子替换；损坏的数据会保留备份。统计日期跟随 Mac 的本地时区。

首次使用摄像头伴练时出现系统授权请求；拒绝后可用“无摄像头纯计时”继续。也可从规则设置直接打开摄像头隐私设置。

## 开发与构建

需要 Node.js 22.12+、npm、Xcode Command Line Tools（用于编译 Swift 原生活动监测器）。

```sh
# 从仓库根目录安装共享依赖，再进入桌面工程
npm ci
cd apps/macos
npm start
npm test
npm run smoke
npm run package
# 可在同一台 Mac 上交叉构建两种架构
npm run package:x64
npm run package:arm64
```

- `npm start`：构建界面和原生监测器，然后运行。
- `npm test`：原插件动作测试 + 桌面计时、休眠、暂停、跨天、推迟、记录与数据持久化测试。
- `npm run smoke`：以独立临时数据目录运行 Electron，验证主界面、原生监测、设置、提醒、真实双组倒计时、暂停恢复、自动完成与离线 AI 模型加载。使用合成摄像头，不访问真实摄像头。截图与结果在 `artifacts/`。
- `npm run smoke:startup`：以全新临时数据目录验证冷启动，模拟首次状态延迟与连接失败，检查首次点击“开始伴练”打开练习窗口、重新唤起已最小化的练习窗口、隐藏后重开和主面板最小化恢复。主面板在控件绑定并完成初始状态请求后显示；连接失败时显示提示，后续状态推送可恢复。macOS 窗口接受激活窗口的首次点击。
- `npm run package`：默认构建当前机器架构，可用 `FITGATE_ARCH=x64` 或 `arm64` 指定。分别编译对应架构、以 macOS 13 为最低版本的 Swift 监测器，构建 `.app` 和 ZIP，检查所有 Mach-O 文件的架构、最低系统版本、动态库路径与签名。结果在 `release/`，校验记录为 `compatibility-<arch>.json`。
- `node scripts/verify-package.mjs release/FitGate-darwin-x64/FitGate.app x64`：独立复核安装包。将两处架构改为 `arm64` 可复核 M 系列版本。
- GitHub Actions 在 macOS 15 的 Intel 和 Apple Silicon 环境分别运行单元测试、原生构建与核心桌面功能冒烟测试。由于托管环境无法初始化 GPU，CI 显式设置 `FITGATE_SKIP_CAMERA=1`，报告中标记摄像头/AI 测试未执行；完整摄像头与离线模型测试在本机运行。所有冒烟测试使用临时设置目录，结果以工作流附件保存。

桌面端采用 Electron + Swift NSWorkspace。渲染进程启用 sandbox、context isolation，禁用 Node integration；预加载桥接只暴露有限 IPC；资源来自受约束的本地 `fitgate://app/` 协议。

主要目录：

| 目录 | 内容 |
| --- | --- |
| `electron/` | 原生窗口、菜单栏、电源事件、权限、持久化、计时引擎 |
| `native/` | Swift 前台应用采样器 |
| `src/desktop.*` | 桌面主面板与设置 |
| `src/reminder.*` | 全屏遮挡与居中休息提醒卡片 |
| `src/workout/` | 从插件复用的本地 AI 与计时伴练 |
| `src/shared/` | 动作定义、规则、音效、设计令牌及兼容桥接 |
| `scripts/` | macOS 打包与端到端冒烟验证 |

实现所用接口参考：[Electron powerMonitor](https://www.electronjs.org/docs/latest/api/power-monitor)、[本地协议](https://www.electronjs.org/docs/latest/api/protocol)、[摄像头授权](https://www.electronjs.org/docs/latest/api/system-preferences)。

## 全屏提醒

提醒复用原插件的卡片、动作信息和双按钮结构，配色、字体、圆角及按钮与桌面主面板统一：浅灰底、白色卡片、灰绿色信息区与深绿色主按钮。界面采用事实与操作文案。没有视频、熊猫图片或呼吸画布；旧动画素材不参与构建。设置中的“预览提醒”可查看弹窗，预览不会开启真实休息周期。

打包可通过 `FITGATE_ELECTRON_ZIP_DIR` 指定已有 Electron ZIP 所在目录，避免重复下载；文件名需与项目 Electron 版本及架构一致。

趋势图支持点击下钻：日、周、月视图点击日期柱查看当天明细；年视图点击月份进入该月，再选择日期。使用记录、活动记录及单应用、单动作详情遵循相同交互，保留当前应用或动作筛选。未来日期不可点击，零记录日期显示空状态。

趋势下钻后显示“返回上一层”，恢复之前的日期、统计周期及图表滚动位置。年 → 月 → 日可以逐层返回；在日视图继续选其他日期时保留原来的周/月入口。使用记录、活动记录及单应用、单动作详情各自保存返回路径，重新选择统计周期或从总览进入时开始新的路径。

点击记录顶部的日期可打开日历，直接修改年份、选择月份和日期，跳到当天明细。四种记录页面使用同一日历，支持今天、关闭或 Escape 取消，并保留原来的返回层级。未来日期不可选。

## 摄像头站位说明

练习画面上方统一显示当前动作的站位和入镜范围，切换动作时同步更新；纯计时模式隐藏此提示。以下为当前识别规则对应的拍摄建议。

| 动作 | 镜头方向 | 入镜与动作方向说明 |
| --- | --- | --- |
| 坐姿侧头舒展 | 躯干正对摄像头 | 让面部和双肩入镜；身体保持朝前，只将头倒向一侧。 |
| 耳朵找肩膀 | 躯干正对摄像头 | 让面部、双肩和扶头的手入镜；身体保持朝前，只做头部侧倾。 |
| 低头看腋窝 | 躯干正对摄像头 | 让面部、双肩和扶头的手入镜；躯干朝前，只转头后低头，不要整个人转成侧身。 |
| 手按锁骨看斜上方 | 躯干正对摄像头 | 让面部、双肩和锁骨区域入镜；躯干朝前，再按步骤转头看斜上方。 |
| 托住后脑低头 | 躯干正对摄像头 | 让面部、双肩和双肘入镜；双手托在脑后，保持身体朝前。 |
| 站立 5 分钟 | 正对摄像头站立 | 让双肩、髋部和双膝入镜，无需拍到脚踝。 |
| 举手翻掌 | 正对摄像头站立 | 让头部、双肩和抬起的双臂入镜；尽量为举过头顶的双手留出画面空间。 |
| 胳膊向后旋 | 正对摄像头站立 | 让双肩、双肘和双手入镜；画面两侧留出双臂平举的空间。 |
| 扶腰后伸 | 建议斜侧身对着摄像头 | 让头部、肩部、髋部和托腰的手或手肘入镜，便于看清上身后伸。 |
| 站姿小燕飞 | 侧身或斜侧身对着摄像头 | 让头部、肩部、髋部及向后伸展的手臂入镜；镜头这一侧的肩、肘、手腕不要被身体挡住。 |
| 交叉腿叉腰侧屈 | 躯干正对摄像头 | 让双肩、髋部和手臂入镜；保持身体朝前，向画面左、右侧屈，不是侧身对着镜头。 |
| 标准深蹲 | 建议侧身对着摄像头 | 先站直并保持片刻，让同一侧的肩部、髋部和膝盖入镜，无需拍到脚踝；下蹲后站直才计次。 |
| 开合跳 | 正对摄像头站立 | 让双肩、双臂和双膝入镜；画面上方及两侧留出手臂举起和双腿张开的空间。 |

## 免打扰应用

在“规则设置 → 免打扰应用”勾选正在运行的会议或演示应用。默认不勾选。选中的应用在前台时，预告通知暂不发送；达到使用上限后，菜单栏显示“待提醒”，继续按原监控范围统计使用时间。切到其他应用后显示提醒；从首次到期开始，最多顺延 60 分钟，重启或切换免打扰应用不会延长这个期限。顺延本身不增加提醒或推迟次数。

此功能依据前台应用，不检测是否正在开会、使用麦克风或投屏。会议中需要切换多个应用时，可使用已有的定时暂停。连续空闲达到设定的休息时长仍会重置本轮。
