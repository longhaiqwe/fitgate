# FitGate - 居家办公深蹲防沉迷 Chrome 插件 🏋️‍♂️

> 借鉴 `cat-gatekeeper` 的防沉迷与锁屏拦截思想，结合 **Google MoveNet 本地 AI 视觉姿态识别**。在 X (Twitter) 等网站使用时间达标后强制锁定网页，必须在摄像头前完成指定数量的标准深蹲，方可解锁继续浏览！

---

## ✨ 核心亮点

1. **真实监控，拒绝作弊**：
   - 内置 MoveNet Lightning 人体骨骼姿态检测神经网络。
   - 采用「髋-膝-踝」三点夹角几何算法与严格有限状态机（FSM）。
   - 必须完全下压至有效深度（膝角 $\le 100^\circ$）并完全站直（$> 155^\circ$）才计 1 次，半蹲或快速抖动镜头均不计次。
2. **100% 本地运算，守护隐私**：
   - 视频流与 AI 推理全部在浏览器本地完成，**没有任何视频或图像数据上传云端**。
3. **坚固的 Shadow DOM 锁屏**：
   - 采用封闭式 Shadow DOM 彻底隔离 X 网页自身 CSS 样式，杜绝样式污染。
   - 阻断底层滚轮与翻页快捷键，内置 `MutationObserver` 防审查元素强制删除。
4. **原生无依赖音效合成**：
   - 基于 Web Audio API 动态合成触底“叮”提示音、计数鼓励音与通关胜利和弦，零外链音频文件。
5. **高度可定制**：
   - 点击插件图标可设置使用时长上限（5~60 分钟）、目标深蹲次数（3~30 次）、管理受控网站（默认 x.com，可添加任何网站）。
   - 提供「立即打开健身房测试」快捷按钮，无需等待超时即可测试。

## 🚀 安装与使用教程

### 1. 编译构建
本项目已配置自动化打包，在项目根目录下执行：
```bash
npm run build
```
执行完毕后，根目录下将生成符合 Chrome Manifest V3 规范的完整 `dist/` 文件夹。

### 2. 在 Chrome 中加载插件
1. 打开 Chrome 浏览器，在地址栏输入并回车：`chrome://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
4. 选择本项目下的 **`dist`** 文件夹即可完成加载。

### 3. 快速体验与功能验证
- **方法一（直接测试健身房）**：
  1. 点击浏览器右上角插件拼图图标，固定 **FitGate** 插件。
  2. 点击 FitGate 图标，点击弹窗底部的 **「🚀 立即打开健身房测试」**。
  3. 允许摄像头权限，站在摄像头前（确保拍到双腿），尝试做几次深蹲，感受骨骼连线、触底变绿提示音与自动计数。
- **方法二（测试网页防沉迷锁屏）**：
  1. 点击 FitGate 弹窗，将「连续使用上限」滑块调节为 **1 分钟**。
  2. 打开并浏览 `https://x.com`。
  3. 活跃停留 1 分钟后，页面将弹出锁屏遮罩阻断浏览，点击「立即前往健身房解锁」，做完深蹲后网页自动解除锁定！
