# FitGate - 居家办公多场景防沉迷健身伴练 Chrome 插件 🏋️‍♂️🧘‍♀️

> 借鉴 `cat-gatekeeper` 的防沉迷与锁屏拦截机制，结合 **本地 AI 姿态检测** 与 **工位场景微运动伴练**。在 X (Twitter) 等网站使用时间达标后触发锁屏，根据用户所处场景（办公室不可站起 / 办公室可站起 / 居家大动作）完成对应动作舒展，方可解锁继续浏览！

---

## ✨ 核心亮点

1. **场景化动作库（针对不同人群与环境）**：
   - 🪑 **办公室 · 坐姿（不可站起来）**：完全坐在椅子上完成，动作隐蔽不引人注目。包含 5 个原著动作：背后交扣侧头、耳朵找肩膀、低头看腋窝、手按锁骨看斜上方、托后脑低头。
   - 🚶 **办公室 · 站立（可站起来）**：站在工位旁或墙边舒展胸背与腰椎。包含 5 个原著动作：举手翻掌、胳膊向后旋、靠墙开胸、扶腰后伸、站姿小燕飞。
   - 🏠 **居家办公 · 大动作（全身活动）**：动作幅度大，借助 Google MoveNet 本地 AI 骨骼姿态识别与三点夹角算法，完成标准深蹲计数解锁。
   - 🎲 **全场景智能轮换**：支持自动轮换或自选指定动作。
2. **原著图文与安全防伤指引**：
   - 完整收录原著动作指导高清示意图。
   - 明确标注「🎯 管什么」、「📋 怎么做」以及「⚠️ 做对了 / 疼就停」的核心安全准则（如手麻、刺痛或头晕立即停）。
3. **智能伴练与节奏器**：
   - 支持单次保持（30s）、双侧轮换（换侧提示音）以及循环重复（8 次，后伸与还原节拍）。
   - 针对工位拉伸无需强制开启摄像头；同时提供可选的画中画对照自拍镜。
4. **100% 本地运算，守护隐私**：
   - AI 视觉推理与视频流完全在本地完成，绝不上云。
5. **封闭式 Shadow DOM 强效锁屏**：
   - 隔离目标网页样式，阻断底层滚动，内置防审查元素篡改监听。
6. **原生 Web Audio 音效**：
   - 触底“叮”、换侧提醒、循环完成与通关和弦原生合成，零外链依赖。

## 🛠️ 安装与使用

### 1. 编译构建
```bash
npm run build
```
执行完毕后，根目录下将生成符合 Chrome Manifest V3 规范的完整 `dist/` 文件夹。

### 2. 在 Chrome 中加载插件
1. 打开 Chrome 浏览器，在地址栏输入并回车：`chrome://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
4. 选择本项目下的 **`dist`** 文件夹即可完成加载。

### 3. 测试与验证
- **运行全量算法与数据测试**：
  ```bash
  npm test
  ```
  包含 20 项单元与稳定性测试（动作数据校验、设置持久化、拉伸节拍器、深蹲夹角与状态机、丢帧恢复）。
- **快捷体验伴练功能**：
  点击插件弹窗顶部的「🚀 立即开始活动 / 伴练打卡」，即可随时体验当前场景下的动作教学图、倒计时伴练、换侧音效与一键切换动作功能。
